คุยกับคน

วิดีโอคอลกับคนอื่นแบบ peer-to-peer แชร์ รหัสห้อง หรือกรอกรหัสของอีกฝ่ายเพื่อเชื่อมต่อ

  • กด คัดลอก เพื่อคัดลอกรหัสห้องของคุณแล้วส่งให้อีกฝ่าย
  • วางรหัสของอีกฝ่ายในช่องกรอกรหัส แล้วกด เข้าร่วม
  • ไอคอน 🔊 ในส่วนหัวแชท — ให้อีกฝ่ายได้ยินข้อความของคุณเป็นเสียงพูด

โหมดนี้ยังมี แผงควบคุมหุ่นยนต์ ให้ใช้งานด้วย — ควบคุมหัวหุ่น InMoov ขณะคุยกับอีกฝ่ายที่เชื่อมต่ออยู่ในห้องเดียวกัน (เช่นจอ /face ของหุ่นยนต์)

  • จอยสติ๊ก (ซ้าย) — ลากเพื่อหมุนลูกตาซ้าย/ขวา/บน/ล่าง
  • D-pad (ขวา) — ◄► หันหัว, ▲ ปิดปาก ▼ เปิดปาก — กดค้างเพื่อขยับต่อเนื่อง หรือแตะสั้น ๆ เพื่อขยับทีละก้าว
  • ปุ่ม ⦿ — รีเซ็ตทุกแกนกลับตำแหน่งกลาง
  • TalkBack / Screen reader — แตะสองครั้ง (double-tap) ที่ปุ่ม D-pad เพื่อขยับทีละก้าวใหญ่พร้อมเสียงบอกตำแหน่ง — ลูกตา: แตะจอยสติ๊กตรงไหนก็ได้หนึ่งครั้งเพื่อโฟกัส แล้วปัดขึ้น/ลง = ตาขึ้น/ลงทีละ 25% ส่วนตาซ้าย/ขวาให้ปัดไปที่ปุ่ม ตาซ้าย / ตาขวา ที่อยู่ถัดจากจอย หรือแตะสองครั้งค้างนิ้วแล้วลากเพื่อคุมสองแกนพร้อมกัน — เมื่อเริ่มลากได้ระบบจะพูด "ควบคุมได้แล้ว" หนึ่งครั้งต่อการลาก (ไม่พูดซ้ำจนกว่าจะปล่อยนิ้วแล้วลากใหม่) — ระหว่างลากเครื่องจะสั่นบอกแทนการพูด: สั่นสั้นทุกขั้นที่ตาขยับ สั่นยาวเมื่อสุดขอบ สั่นสองครั้งเมื่อตากลับกึ่งกลาง
คีย์บอร์ดควบคุม

ใช้แป้นพิมพ์แทนการกดปุ่มหน้าจอได้ (ใช้งานได้เมื่อไม่ได้พิมพ์อยู่ในช่องแชทหรือช่องกรอกข้อความอื่น ๆ)

  • ลูกศร ◄►▲▼ — ควบคุม D-pad (หันหัว / เปิดปิดปาก) กดหลายทิศทางพร้อมกันได้ — ใช้ได้เฉพาะในโหมด คุยกับคน
  • Space — รีเซ็ต D-pad กลับตำแหน่งกลาง (เหมือนกดปุ่ม ⦿) — ใช้ได้เฉพาะในโหมด คุยกับคน
  • W A S D — ควบคุมจอยสติ๊ก (ลูกตาบน/ล่าง/ซ้าย/ขวา) — ใช้ได้เฉพาะในโหมด คุยกับคน
  • Alt ซ้าย — เปิด/ปิด Speech (STT) เหมือนกดปุ่ม Speech
  • Alt ขวา — เปิด/ปิดเสียงข้อความของคุณให้คู่สนทนาฟัง (เหมือนปุ่ม 🔊 ในหัวแชท)
  • ขณะพิมพ์อยู่ในกล่องข้อความใด ๆ ปุ่มเหล่านี้จะไม่ทำงาน เพื่อไม่ให้รบกวนการพิมพ์
การพูด (STT)

กดปุ่ม พูด เพื่อเริ่มฟัง ระบบจะแปลงเสียงเป็นข้อความแล้วส่งให้คู่สนทนาโดยอัตโนมัติ

  • โหมด Browser STT (ค่าเริ่มต้น) — ใช้ระบบรู้จำเสียงของเบราว์เซอร์ (ผ่านบริการของ Google) ทำงานต่อเนื่อง ต้องใช้ Chrome/Edge
  • โหมด Whisper — บันทึกเสียงจนเงียบแล้วส่งถอดความผ่าน Groq หลังพูดจบจะเริ่มฟังใหม่เอง
  • เปลี่ยนโหมดได้ที่ Settings → Speech-to-Text Mode
เสียงข้อความ (TTS)

ข้อความจากคู่สนทนาจะถูกอ่านออกเสียงอัตโนมัติเมื่อเปิดใช้งาน ผ่าน Text-to-Speech ของเบราว์เซอร์

  • ทุกข้อความมีปุ่ม 🔊 เพื่อเปิดเสียงซ้ำได้ทุกเมื่อ
  • บน iOS ให้กดปุ่มใดก็ได้ก่อนเพื่อปลดล็อกเสียง
การตั้งค่า ⚙
  • MQTT Broker URL — URL WebSocket ของ Mosquitto broker สำหรับส่งคำสั่งไปยัง Arduino
  • TURN servers — เพิ่ม TURN server เองหากต้องการโทรข้ามเครือข่าย
ปุ่มควบคุม
  • ไมค์ — เปิด/ปิดไมโครโฟน
  • กล้อง — เปิด/ปิดกล้อง
  • พูด — เปิด/ปิดการรับรู้เสียง
  • วางสาย — วางสายหรือตัดการเชื่อมต่อกับคู่สนทนา
  • 🔊 (หัวแชท) — ให้อีกฝ่ายได้ยินข้อความของเราเป็นเสียงพูด
